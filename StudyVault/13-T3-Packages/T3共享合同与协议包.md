# T3共享合同与协议包（重要度 ★★★）

#module-t3-packages #pattern-rpc

## Purpose

在服务端和各客户端间共享 Schema、协议、平台抽象及通用工具，避免各端独立猜测消息格式。供应商协议客户端、SSH 与 Tailscale 接入也位于包边界中。

## Public Interface

| 接口或入口 | 行为 |
| --- | --- |
| `@t3tools/contracts` | 共享命令、事件、RPC 与错误类型/Schema |
| `@t3tools/client-runtime/<subpath>` | 连接、鉴权、RPC、平台能力与领域状态 |
| `effect-codex-app-server / effect-acp` | 各自协议的公开 client/schema 等子路径 |
| `@t3tools/shared / ssh / tailscale` | 通用业务工具、SSH 隧道与网络接入 |

## Internal Flow

```text
contracts 的 Schema/命令/事件
  +-> Server: 注册和验证 RPC -> 领域服务
  +-> client-runtime: 类型化 RPC -> 共享连接/状态
  +-> Web / Desktop / Mobile 平台实现
供应商服务 -> effect-codex-app-server 或 effect-acp -> 实际进程
```

TypeScript 类型在编译时提供约束，运行期网络输入仍需 Schema 校验。client-runtime 的公共边界由 package exports 决定，不应直接导入私有内部文件。shared 提供跨端通用逻辑，不能替代供应商协议实现。ssh 与 tailscale 是连接能力，源码存在不代表当前机器已完成远程配对或路由验证。

包清单：client-runtime、contracts、effect-acp、effect-codex-app-server、shared、ssh、tailscale。运行时工程还使用 node-pty、SQLite、React/Electron、Effect 等第三方依赖，具体安装版本以对应清单和锁文件为准。

## Testing

从项目根目录开启新的终端后执行：

```powershell
Set-Location t3-source
vp run --filter @t3tools/contracts test
vp run --filter effect-acp typecheck
```

Schema、协议与共享逻辑测试；真实服务进程/远程网络另验。

命令为学习入口，本次建库未执行项目测试或真实服务调用。模块构建与平台要求见 [[构建测试与发布]]。
