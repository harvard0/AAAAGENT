# T3客户端与共享状态（重要度 ★★★）

#module-t3-client #pattern-rpc

## Purpose

呈现工作台线程、项目、终端和结果，并通过共享 client-runtime 连接环境、调用 RPC 和消费领域状态。网页与桌面能力通过有限平台接口适配。

## Public Interface

| 接口或入口 | 行为 |
| --- | --- |
| `main.tsx startup / AppRoot / router` | 加载初始路由与所选运行环境后渲染 |
| `createOrchestrationEnvironmentAtoms` | 从连接 runtime 派生编排状态 |
| `createLocalApi / readLocalApi` | 有限宿主能力与浏览器回退 |
| `@t3tools/client-runtime/rpc 与 state/<domain>` | 共享连接、RPC、订阅及领域状态公共子路径 |

## Internal Flow

```text
main.tsx -> AppRoot + TanStack Router -> 页面/组件
  -> connection runtime -> client-runtime/rpc -> T3 Server
  <- 订阅与投影 -> state/<domain> -> UI
平台能力 -> localApi / desktopBridge -> 桌面宿主或浏览器回退
```

Electron 文件壳使用 hash history，浏览器使用 browser history。预览接线仅在 VITE_AAA_PREVIEW=1 时安装，不代表真实后端任务完成。shared client-runtime 没有根导出，也没有宽泛的 state 导出，需导入明确子路径。页面展示状态、连接身份、命令回执与领域事件应分别核对；只更新一份组件状态不能修复丢失的事件。

主要领域：routes/components 组织页面；connection/environments/onboarding 负责接入；state/rpc 承接共享状态；terminal/browser 负责工具界面；aaaagent/aaaIntegration 是项目覆盖与预览接缝；cloud、observability、hooks、lib、assets、vendor、test 是相应接入与辅助。apps/mobile 保留源码，但本仓库快照未打包 SDK 或二进制，不作为已验收移动产品。

## Configuration

| 字段或环境 | 用途与限制 |
| --- | --- |
| `VITE_AAA_PREVIEW` | 值为 1 时安装隔离预览 transport |
| `VITE_CLERK_PUBLISHABLE_KEY / cloud public config` | 共同决定是否加载托管认证外壳 |
| `VITE_HTTP_URL / VITE_WS_URL` | 开发 runbook 要求通常保持未设置，以同源代理连接 |
| `appearance-mode` | 统一主题偏好通过既有接缝同步；不能携带业务凭据 |

## Testing

从项目根目录开启新的终端后执行：

```powershell
Set-Location t3-source
vp run --filter @t3tools/web typecheck
vp run --filter @t3tools/web test
```

TypeScript 与前端单元测试；真实浏览器、布局和原生同步需要另外验证。

命令为学习入口，本次建库未执行项目测试或真实服务调用。模块构建与平台要求见 [[构建测试与发布]]。
