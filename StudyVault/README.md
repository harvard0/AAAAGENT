# StudyVault使用说明

#dashboard #onboarding

在 Obsidian 选择“打开文件夹作为仓库”，选择本项目的 `StudyVault/`，然后打开 [[AAAAGENT学习地图]]。不依赖社区插件；普通 Markdown 阅读器也能查看内容，wiki 链接和折叠 callout 的呈现取决于阅读器。

所有源码路径均相对 **AAAAGENT 项目根目录**，不是相对当前笔记。Key Files 给出行号和符号，方便回到源码核对；笔记之间使用 Obsidian wiki-links。

先独立作答再展开练习中的“查看答案”。本库有 12 个领域、每个领域 5 题，包含代码阅读、配置、调试、扩展与边界分析。扩展题提供实现方向，不代表已经修改项目代码。

本库基于 2026-10-24 当前源码构建，只读取项目来源及经用户许可的技能配套文档。本次没有启动模型、账号、桌面应用或付费服务。详细检查结果见 [[建库自检]]。
