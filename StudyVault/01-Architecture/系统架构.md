# 系统架构

#arch-system

## 架构判断

AAAAGENT 是多进程桌面系统：本机陪伴后端以端口接口编排领域逻辑，独立社交服务负责群参与经历，T3 工作台负责工程执行。T3 内部使用 Effect 服务与 Layer，并通过持久领域事件、读投影和反应器协调 Agent。不能把整个仓库简单归类为一个 HTTP 单体，也不能把每个目录都视为独立部署的微服务。

```text
桌面/微信 -> 本机后端 -> 私人对话模型 -> 文字/TTS/角色
                  |        ^
                  |        +-- 私人记忆 + 授权社交缓存
                  +-> 工作确认 -> T3 Server -> Codex/DSH 等执行器
                                      ^          |
                                      +-- 事件 --+
QQ 已送达回复 -> 独立社交服务 -> GET sync -> 本地社交缓存
管理页面 -> 本机管理服务 -> 各领域能力端口
```

## 平台与外部依赖

| 范围 | 技术/外部依赖 | 例外和验证边界 |
| --- | --- | --- |
| 根目录桌宠 | TypeScript、Node、better-sqlite3、Swift/AppKit/WebKit | 构建不证明 Mac 权限与实体设备通过 |
| Windows 桌宠 | 独立 TypeScript 源码、Electron、Windows 原生依赖 | 不能复制 Mac 或 WSL node_modules |
| T3 | React 19、TanStack Router、Effect、vp/pnpm 工作区、SQLite/终端服务 | 依赖的账号、固定引擎及运行包另需准备 |
| 云端能力 | 对话、结构化记忆、摘要、ASR/TTS/图像模型 | 按操作配置，不保证全部离线 |
| 社交平台 | 微信账号、现有 QQ 迁移包与发送回执 | QQ 完整运行包不在仓库中 |
| 可选能力 | 本地模型、SSH/Tailscale、移动端源码 | 有源码不等于权重、网络或移动 SDK 已就绪 |
