# 命令与排查速查

#dashboard #quick-reference

## 运行命令 → [[构建测试与发布]]

每行先进入所列目录；依赖尚未安装时先按平台安装文档准备。

| 目录 | 操作 | 命令 |
| --- | --- | --- |
| `windows/code/desktop-pet` | 安装/类型检查/预览 | `npm.cmd ci` / `npm.cmd run check` / `npm.cmd run dev` |
| `windows/code/desktop-pet` | 平台/社交检查 | `npm.cmd run test:windows` / `npm.cmd run test:social` |
| `code/desktop-pet` | Mac 共享源码类型检查 | `npm.cmd run check`（原生构建仍须 Mac） |
| `windows/local-models` | 初始化/诊断/启动 | `npm.cmd run configure` / `npm.cmd run doctor` / `npm.cmd start` |
| `t3-source` | 安装/开发 | `vp i` / `vp run dev --home-dir .study-dev-state` |
| `t3-source` | 类型/格式/构建 | `vp run typecheck` / `vp run fmt:check` / `vp run build` |
| 项目根目录 | 学习库检查 | `python StudyVault/.tools/validate_vault.py` |

## 环境配置 → [[环境配置与验证边界]]

Node 要求按子项目清单选择；T3 工作区要求 Node 24。Windows CI 自行选择 Node 24.19.0，并不能据此假设本机版本相同。配置激活、外部凭据引用和授权素材按平台准备。

## 调试分流 → [[请求流]]

| 症状 | 首先核对 | 进一步阅读 |
| --- | --- | --- |
| 取消后旧回复出现 | scope、signal、generation 与版本 | [[运行时与对话编排]]、[[桌面宿主与平台边界]] |
| 后台整理失败 | 原文是否保存、任务阶段、隐私 pending | [[私人记忆与上下文]] |
| HTTP 成功但响应无效 | 网络、结构、语义分开核查 | [[模型适配与媒体链路]] |
| 社交不再可引用 | allowedGroups、synced、maxAgeMs、epoch | [[角色社交服务与缓存]] |
| 确认请求超时 | commandId 的原回执；避免重复任务 | [[工作执行与项目上下文]] |
| 管理写入 403/409 | Origin 或 expectedRevision | [[管理HTTP接口]] |
| health 正常但本地模型失败 | doctor、权重、能力别名与后端 | [[Windows本地模型网关]] |
| RPC 接受但页面无结果 | 反应器、供应商、事件投影与订阅 | [[T3服务端与事件编排]]、[[T3客户端与共享状态]] |
