## 内容复核

| 检查点 | 处理 |
| --- | --- |
| 主要领域 | 12 个领域均有专用笔记与 5 题，服务端/客户端辅助目录有分组说明 |
| 架构与流 | ASCII 图区分私人聊天、工程事件和已送达 QQ 摘要 |
| 外部依赖 | 供应商、设备、平台、迁移包及共享协议分别列出 |
| 接口边界 | 管理 HTTP、社交 HTTP、工作台 RPC 使用独立接口笔记 |
| 易错结论 | accepted/完成、health/就绪、默认测试/全仓、模拟/真实投递均明确区分 |
| 平台范围 | 不把根目录 Mac 源码与 windows 当作相同运行包 |
| 来源限制 | 源码抽样分析，无外部项目、私人状态或权重访问；技能配套读取已获许可 |
| 验证限制 | 没有运行项目测试、真实模型、原生应用、设备或 Obsidian 渲染 |
