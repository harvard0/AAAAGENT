# 标签标准

#dashboard #onboarding

## 使用规则

全部标签使用英文小写 kebab-case，只能使用此注册表。层次为 arch/module 主域 → pattern/api 细节 → note-type。模块笔记和练习带对应 module 标签；api 标签必须同时带所属 module 标签。跨模块架构说明使用 arch 标签；构建和质量说明使用 config/test 标签。模块需要扩充时先更新注册表，再创建引用。

这份领域与标签表已由用户批准。文中行内代码展示的标签定义不是额外的主题内容标签。
