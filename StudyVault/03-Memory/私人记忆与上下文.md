# 私人记忆与上下文（重要度 ★★★）

#module-memory #pattern-provenance

## Purpose

持久化私人对话、长期记忆与来源，并在预算内选择允许进入本轮模型请求的上下文。生命周期写入、召回、纠正和遗忘共同维护角色及来源版本边界。

## Internal Flow

```text
用户原文 -> SQLite 对话与来源
  +-> 最近完整轮次 -> assembleContext -> 模型请求
  +-> 后台生命周期 -> 校验提案/来源/版本 -> 长期记忆与摘要
纠正/遗忘 -> 变更来源与版本 -> 旧上下文失效
```

装配先保留必需提示词与当前输入，再为当前情绪预留容量，选取连续的最近完整问答后缀，随后补摘要和相关记忆；不是任意挑选较短的旧消息。maxRecentMessages 与 maxMemories 在 context.ts 中属于兼容字段，不是新的前台数量上限。近期原文、长期记忆、项目索引与社交缓存分开。

排序：P = C × (0.55 + 0.25A + 0.15I + 0.05E)。活动衰减 A(t)=A₀×2^(-t/H)，H=30×(1+2I) 天；情绪默认半衰期 7 天，强化默认 A′=A+0.2(1−A)，稳定记忆活动值为 1。C=0 时优先级仍为 0。自然衰减改变排序，不自动删除记录；参数以 dynamics.ts 为准。
